# 05: 建议措辞（模型）

**What to build:** 在 04 的确定性候选上加一层模型：模型只做两件事，给候选排序、为每条写结论与动作；文本不得含数字，evidence 由服务端按候选 id 回填。模型输出含数字、排序不合法、调用失败时，整条回退 04 的模板并标记为本地规则。发给模型的文本只含规则文件、训练画像、结构化摘要，不含备注原文。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 注入 FakeLLM 返回新措辞后，接口里的 evidence 与数字和 04 逐字一致，只有结论/动作变了。
- [ ] 模型只返回部分候选或非法顺序时，回退脚本顺序，不丢候选。
- [ ] 模型文本含数字（如「80kg」）时整条回退模板，标记为本地规则。
- [ ] 模型抛错或无 key 时，行为与 04 完全一致。
- [ ] 捕获发给模型的文本：含规则文件、画像、4 周摘要；不含备注原文。
- [ ] 测试注入 FakeLLM，不连网。
- [ ] 页面能区分「本地规则」与「模型措辞」；无 key 时仍能出建议。
