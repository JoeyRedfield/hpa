# 04: 确定性建议（无模型）

**What to build:** 点「给我建议」才生成。脚本按三条规则（频率 / 部位间隔、容量趋势、进步停滞）算事实与候选；每条规则最多 1 条候选，总共最多 3 条。每条含结论、带日期与数字的 evidence、一个具体动作，并引用真实 workout id。数据不足时返回「再记 N 次」而不是硬编。没有 API key 或模型失败时用确定性模板，标记为本地规则。结果保存一条，刷新后仍能看到生成时间与内容。
